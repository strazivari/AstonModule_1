# AstonModule_1

Учеюный проект по реализации союственного иммутабельного класса, который будет внутри себя содержать поле с изменяемым классом.



## Требования

- JDK, совместимый с версией Java, указанной в `pom.xml`.
- Apache Maven (при желании).

Проверить установленную Java можно командой:

```bash
java -version
```

## Назначение классов

- **`Address`** хранит город доставки. Это изменяемый класс с конструктором копирования и сеттером `setCity`.
- **`ImmutableOrder`** хранит имя, телефон и адрес. Строковые значения проверяются при создании заказа. Адрес копируется при передаче в конструктор и при возврате из `getAddress()`, чтобы вызывающий код не мог изменить состояние заказа через общий объект `Address`.
- **`ValidationUtils`** содержит общую проверку строковых данных: `null` считается недопустимым значением, а пустая или состоящая из пробелов строка отклоняется.
- **`Main`** показывает защитное копирование на практике: изменение исходного адреса и адреса, полученного через геттер, не меняет город, сохранённый в заказе.

## Как обеспечивается иммутабельность заказа

`Address` сам по себе изменяемый: его город можно заменить после создания объекта. Поэтому недостаточно просто сохранить переданную ссылку на адрес.

`ImmutableOrder` использует защитное копирование в двух местах:

1. При создании заказа сохраняет копию переданного `Address`. Последующие изменения исходного объекта не затрагивают заказ.
2. В `getAddress()` возвращает копию. Изменения объекта, полученного вызывающим кодом, не затрагивают адрес внутри заказа.

Поля заказа `name` и `phone` имеют тип `String`, а строки в Java неизменяемы. В совокупности с отсутствием изменяющих заказ сеттеров и копированием изменяемого адреса это сохраняет состояние заказа после создания.

## Сборка и тестирование

Запустите команды из корневой папки проекта, где находится `pom.xml`:

```bash
mvn test
```

Запускает модульные тесты.

## Запуск `Main`

Сначала скомпилируйте проект, затем запустите главный класс:

```bash
mvn compile
java -cp target/classes org.example.Main
```

В IntelliJ IDEA также можно запустить `Main` через значок запуска рядом с методом `main`.

## Что проверяют тесты

### `AddressTest`

- создание адреса и получение города;
- изменение города;
- создание независимой копии через конструктор копирования;
- отклонение `null` и пустого или состоящего из пробелов города.

### `ImmutableOrderTest`

- сохранение имени, телефона и адреса;
- отклонение недопустимых значений `null` и пустых строк;
- независимость заказа от изменений исходного адреса;
- независимость заказа от изменений адреса, полученного через геттер;
- возврат отдельной копии адреса при вызове геттера.
